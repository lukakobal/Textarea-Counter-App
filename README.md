# ✍️ Textarea Counter App — React Day 22

A simple and practical React app that counts characters in real time while typing into a textarea. Includes validation when the user exceeds the maximum length.

## 🚀 Features
- Controlled textarea
- Live character counter
- Max length limit (120 chars)
- Dynamic red warning
- Error message when limit is exceeded

## 🧠 Concepts Practiced
- `useState`  
- Controlled components  
- Real-time validation  
- Conditional rendering  
- Basic UX patterns

Perfect daily React practice project! 💪
